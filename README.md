## 关于本仓库

这是我自学**计算机与数学**的完整记录：每天一个主题，配「知识点 + 练习」，边学边做小项目，全程用 Git 管理版本与进度。

**读者指引**：想快速了解学习情况，看下面的「学习板块」和「学习亮点」；想看细节，进入对应文件夹即可 —— 每个板块都有独立的 `学习日志.md`，按天记录内容、练习与遇到的问题。

## 关于 AI 协作

学习资料（知识点讲解、练习题与批改）由 AI 助手**辅助**生成；**所有练习均由我本人独立思考、亲手完成，提交后由 AI 批改与点评**，学习规划、方向选择与项目推进均由我主导。

我认为**善用 AI 工具是当下学习与工程中的一项重要能力**，因此如实保留这一协作过程——这也是本仓库的一个特点。
