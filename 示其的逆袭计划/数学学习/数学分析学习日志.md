## 一、为什么学数分（三条线，其实是同一条）

这门课同时服务三件大事，**不是三份工作量**：

| 线 | 数分的作用 |
|----|-----------|
| 🎯 **转专业**（大一上结束申请） | 数分/高代/解几 是 GPA 主战场，**GPA 占综合成绩 70%** |
| 🏆 **数学竞赛**（2026.11.14 初赛） | 数学专业类初赛：**数学分析 50%** + 高等代数 35% + 解析几何 15% |
| 🌱 **长期**（AI 方向 / 408 / 考研数学） | 极限、ε-δ 语言是全部后续数学的地基 |

**所以数分是本学期投入产出比最高的一门课。** 把它学扎实，三件事一起往前走。

## 二、班助工作规则（Claude 担任）

> 示其 2026.9.17 指定：以陈纪修 B 站网课为基础开始数学分析学习，Claude 担任**班助**，解答有关数学分析的一切学习问题。

1. **随时提问，随时答。** 关于数分的任何问题——定义看不懂、证明某一步跳了、题目不会做、视频里老师某句话没懂、作业题卡住——直接在对话里问，不用攒着。
   **回答顺序固定为**：① 先在对话里给完整解答 → ② 再去对应 `知识点.md` 的相关位置补注释 → ③ 最后告诉你标注的具体位置（章节 / 行号）。
2. **练习题里不写答案。** `练习.md` 只放题目；完整解答单独放在同文件夹的 `参考解答.md`。做题时先别翻，做完发我批改——逐题点评错误、给"预估 X/总分"、标出扣分点。
3. **例题精讲先行。** 每讲 `知识点.md` 末尾都有"例题精讲"（2–4 道，含题目 / 思路 / 完整解答 / 关键点）。**先看懂例题，再动练习。**
4. **每讲末尾加一道回顾题**（沿用 Python / Linux 课的规矩）。回顾的是**本课程之前已学**的数分内容；第 01 讲是开篇，改为回顾高中衔接工具（绝对值不等式、均值不等式），从第 02 讲起正式回顾前面讲次。
5. **标注竞赛考点。** 讲义里遇到数学竞赛初赛常考的知识点，会打 🧩 **竞赛视角** 标记（数分占初赛 50%，值得知道哪些是必考）。
6. **学习节奏：不图快，一讲讲透。** 标准流程：看视频 → 读 `知识点.md` → 做例题精讲 → 做 `练习.md` → 发我批改 → 过关再进下一讲。
7. **与学校课程联动。** 学校《数学分析》课的作业、小测、考试题，同样可以拿来问——学校课和视频课进度可能不同步，两边有出入时以**学校课的进度和教材**为准（期末考的是学校老师的卷子）。
